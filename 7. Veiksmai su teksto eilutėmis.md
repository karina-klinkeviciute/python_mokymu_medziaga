# Darbas su eilutėmis (`string`)

Eilutė (`str`) – tai tekstas.

```python
vardas = "Karina"
miestas = 'Kaunas'
```

Eilutės yra **nekintamos** (*immutable*). Tai reiškia, kad pakeitus tekstą sukuriama nauja eilutė.

```python
vardas = "Karina"

naujas = vardas.upper()

print(vardas)   # Karina
print(naujas)   # KARINA
```

---

# Indeksavimas

Kiekvienas simbolis turi numerį (indeksą).

```text
"K a r i n a"
 0 1 2 3 4 5
```

Galima paimti vieną simbolį.

```python
tekstas = "Python"

print(tekstas[0])
```

Rezultatas:

```text
P
```

Paskutinis simbolis:

```python
print(tekstas[-1])
```

```text
n
```

---

# Slicing

Slicing leidžia paimti dalį eilutės.

Bendra forma:

```python
eilute[pradzia:pabaiga]
```

Imami simboliai nuo `pradzia` iki `pabaiga`, bet **pabaigos indeksas neįtraukiamas**.

```python
tekstas = "Python"

print(tekstas[0:2])
```

```text
Py
```

Nuo pradžios:

```python
print(tekstas[:3])
```

```text
Pyt
```

Iki galo:

```python
print(tekstas[2:])
```

```text
thon
```

Visa eilutė:

```python
print(tekstas[:])
```

```text
Python
```

Kas antras simbolis:

```python
print(tekstas[::2])
```

```text
Pto
```

Apversta eilutė:

```python
print(tekstas[::-1])
```

```text
nohtyP
```

# `startswith()`

Patikrina, ar eilutė prasideda nurodytu tekstu.

```python
tekstas = "Python yra smagus"

print(tekstas.startswith("Python"))
```

```text
True
```

```python
print(tekstas.startswith("Java"))
```

```text
False
```

Dažnai naudojama:

```python
if failas.startswith("data_"):
    print("Tai duomenų failas")
```

---

```python
print(failas.endswith(".pdf"))
```

```text
True
```

# `replace()`

Pakeičia vieną tekstą kitu.

```python
tekstas = "Labas pasauli"

naujas = tekstas.replace("pasauli", "Python")

print(naujas)
```

```text
Labas Python
```

Originali eilutė nepasikeičia.

Galima nurodyti, kiek kartų keisti.

```python
tekstas = "a a a a"

print(tekstas.replace("a", "b", 2))
```

```text
b b a a
```

---

# `split()`

Skaido eilutę į sąrašą.

```python
tekstas = "obuolys kriaušė slyva"

print(tekstas.split())
```

```text
['obuolys', 'kriaušė', 'slyva']
```

Naudojant kitą skirtuką:

```python
csv = "Jonas,20,Kaunas"

print(csv.split(","))
```

```text
['Jonas', '20', 'Kaunas']
```

Galima riboti skaidymų skaičių.

```python
tekstas = "a-b-c-d"

print(tekstas.split("-", 2))
```

```text
['a', 'b', 'c-d']
```

---

# `join()`

Sujungia sąrašo elementus į vieną eilutę.

```python
zodziai = ["Labas", "pasauli"]

tekstas = " ".join(zodziai)

print(tekstas)
```

```text
Labas pasauli
```

Su kableliais:

```python
vaisiai = ["obuolys", "kriaušė", "slyva"]

print(", ".join(vaisiai))
```

```text
obuolys, kriaušė, slyva
```

Be skirtuko:

```python
skaiciai = ["1", "2", "3"]

print("".join(skaiciai))
```

```text
123
```

---

# `strip()`

Pašalina tarpus pradžioje ir pabaigoje.

```python
tekstas = "   Labas   "

print(tekstas.strip())
```

```text
Labas
```

Tik iš kairės:

```python
tekstas.lstrip()
```

Tik iš dešinės:

```python
tekstas.rstrip()
```

Galima šalinti konkrečius simbolius.

```python
tekstas = "---Labas---"

print(tekstas.strip("-"))
```

```text
Labas
```


```python
tekstas = tekstas.upper()
```

arba


## Painiojami `split()` ir `join()`

`split()` eilutę paverčia sąrašu.

```python
"Labas pasauli".split()
```

Rezultatas:

```python
['Labas', 'pasauli']
```

`join()` sąrašą paverčia eilute.

```python
" ".join(["Labas", "pasauli"])
```

Rezultatas:

```text
Labas pasauli
```
