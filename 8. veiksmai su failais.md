# Python: darbas su failais ir katalogais

Python programos gali ne tik laikyti duomenis atmintyje, bet ir **skaityti duomenis iš failų bei juos išsaugoti failuose**.

Pavyzdžiui, programa gali:

* perskaityti tekstą iš `.txt` failo;
* išsaugoti vartotojo įvestus duomenis;
* papildyti jau egzistuojantį failą;
* patikrinti, ar failas egzistuoja;
* kurti katalogus;
* peržiūrėti kataloge esančius failus.

---

# 1. Failo atidarymas

Darbui su failais Python turi funkciją `open()`.

```python
file = open("hello.txt")
```

Ši komanda bando atidaryti failą `hello.txt`.

Pagal nutylėjimą failas atidaromas **skaitymui**.

Baigus darbą failą reikia uždaryti:

```python
file.close()
```

Taigi paprasčiausias darbo su failu pavyzdys:

```python
file = open("hello.txt")
content = file.read()
print(content)
file.close()
```

Jeigu `hello.txt` turinys yra:

```text
Hello!
Welcome to Python.
```

programa išves:

```text
Hello!
Welcome to Python.
```

---

# 2. `with open(...)`

Praktiškai failams atidaryti dažniausiai naudojama `with` konstrukcija:

```python
with open("hello.txt") as file:
    content = file.read()
    print(content)
```

Jos privalumas – Python automatiškai uždaro failą, kai darbas su juo baigiamas.

Todėl nereikia rašyti:

```python
file.close()
```

Rekomenduojama failus atidaryti būtent naudojant `with`.

---

# 3. Failo koduotė

Dirbant su tekstiniais failais verta nurodyti jų koduotę:

```python
with open("hello.txt", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

UTF-8 leidžia saugiai dirbti su lietuviškomis raidėmis ir kitais Unicode simboliais.

Pavyzdžiui:

```text
Ąžuolas
Šaltinis
Žąsis
```

Todėl tekstiniams failams dažnai naudosime:

```python
encoding="utf-8"
```

---

# 4. Failo skaitymas su `read()`

Metodas `read()` perskaito visą failo turinį:

```python
with open("animals.txt", encoding="utf-8") as file:
    content = file.read()

print(content)
```

Jeigu faile yra:

```text
Katė
Šuo
Žiurkėnas
```

kintamajame `content` bus viena tekstinė reikšmė (`str`):

```python
"Katė\nŠuo\nŽiurkėnas\n"
```

`\n` reiškia naują eilutę.

---

# 5. Failo skaitymas eilutėmis

Failą galima skaityti ir po vieną eilutę:

```python
with open("animals.txt", encoding="utf-8") as file:
    for line in file:
        print(line)
```

Tačiau galime pastebėti, kad tarp eilučių atsiranda papildomi tarpai.

Taip nutinka todėl, kad pati eilutė jau baigiasi simboliu `\n`, o `print()` taip pat prideda naują eilutę.

Galime pašalinti tarpus eilutės pradžioje ir pabaigoje naudodami `strip()`:

```python
with open("animals.txt", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

Rezultatas:

```text
Katė
Šuo
Žiurkėnas
```

---

# 6. `readlines()`

Metodas `readlines()` perskaito failo eilutes į sąrašą:

```python
with open("animals.txt", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
```

Galimas rezultatas:

```python
["Katė\n", "Šuo\n", "Žiurkėnas\n"]
```

Galime pašalinti `\n`:

```python
with open("animals.txt", encoding="utf-8") as file:
    lines = []

    for line in file:
        lines.append(line.strip())

print(lines)
```

Rezultatas:

```python
["Katė", "Šuo", "Žiurkėnas"]
```

Tą patį galima užrašyti trumpiau:

```python
with open("animals.txt", encoding="utf-8") as file:
    lines = [line.strip() for line in file]
```

---

# 7. Failų atidarymo režimai

`open()` funkcijai galima nurodyti, ką norime su failu daryti.

Svarbiausi režimai:

| Režimas | Reikšmė             |
| ------- | ------------------- |
| `"r"`   | skaityti (read)     |
| `"w"`   | rašyti (write)      |
| `"a"`   | papildyti (append)  |
| `"x"`   | sukurti naują failą |

Pavyzdžiui:

```python
open("data.txt", "r")
```

atidaro failą skaitymui.

```python
open("data.txt", "w")
```

atidaro failą rašymui.

---

# 8. Rašymas į failą

Norėdami rašyti į failą naudojame režimą `"w"`:

```python
with open("message.txt", "w", encoding="utf-8") as file:
    file.write("Labas!")
```

Bus sukurtas failas:

```text
message.txt
```

kurio turinys:

```text
Labas!
```

Jeigu failas jau egzistuoja, `"w"` režimas **ištrina seną jo turinį**.

Pavyzdžiui, jei faile buvo:

```text
Senas tekstas
```

įvykdžius:

```python
with open("message.txt", "w", encoding="utf-8") as file:
    file.write("Naujas tekstas")
```

faile liks tik:

```text
Naujas tekstas
```

Todėl su `"w"` reikia būti atsargiems.

---

# 9. Kelių eilučių rašymas

Naują eilutę žymi `\n`:

```python
with open("animals.txt", "w", encoding="utf-8") as file:
    file.write("Katė\n")
    file.write("Šuo\n")
    file.write("Žiurkėnas\n")
```

Rezultatas:

```text
Katė
Šuo
Žiurkėnas
```

Galime rašyti ir duomenis iš sąrašo:

```python
animals = ["Katė", "Šuo", "Žiurkėnas"]

with open("animals.txt", "w", encoding="utf-8") as file:
    for animal in animals:
        file.write(animal + "\n")
```

# 10. Failo papildymas

Kartais nenorime perrašyti seno failo – norime pridėti duomenų jo pabaigoje.

Tam naudojamas režimas `"a"`:

```python
with open("animals.txt", "a", encoding="utf-8") as file:
    file.write("Triušis\n")
```

Jeigu prieš tai faile buvo:

```text
Katė
Šuo
```

po programos vykdymo bus:

```text
Katė
Šuo
Triušis
```

---

# 11. Failo sukūrimas su `"x"`

Režimas `"x"` sukuria naują failą:

```python
with open("new.txt", "x", encoding="utf-8") as file:
    file.write("Naujas failas")
```

Svarbus skirtumas nuo `"w"`:

* `"w"` perrašo failą, jeigu jis jau egzistuoja;
* `"x"` tokiu atveju pateikia klaidą.

Todėl `"x"` naudingas, kai nenorime netyčia perrašyti egzistuojančio failo.

# 12. Kas yra failo kelias?

Failą nurodome naudodami jo **kelią** (angl. *path*).

Pavyzdžiui:

```text
animals.txt
```

arba:

```text
data/animals.txt
```

Antruoju atveju failas `animals.txt` yra kataloge `data`.

Struktūra galėtų atrodyti taip:

```text
project/
├── main.py
└── data/
    └── animals.txt
```

Tada `main.py` galime rašyti:

```python
with open("data/animals.txt", encoding="utf-8") as file:
    print(file.read())
```

# 13. Santykiniai ir absoliutūs keliai

Egzistuoja du pagrindiniai kelių tipai.

## Santykinis kelias

```text
data/animals.txt
```

Jis nurodo failo vietą **dabartinio darbinio katalogo atžvilgiu**.

## Absoliutus kelias

Jis nurodo visą failo vietą kompiuteryje.

Linux sistemoje:

```text
/home/user/projects/python/data/animals.txt
```

Windows sistemoje:

```text
C:\Users\User\projects\python\data\animals.txt
```

Programose dažniausiai patogiau vengti konkrečiam kompiuteriui pririštų absoliučių kelių.

# 14. `pathlib`

Šiuolaikiniame Python darbui su failų ir katalogų keliais labai patogu naudoti standartinės bibliotekos modulį `pathlib`.

Importuojame `Path`:

```python
from pathlib import Path
```

Tada galime sukurti kelią:

```python
path = Path("data")
```

arba kelią iki failo:

```python
path = Path("data/animals.txt")
```

---

# 15. Kelių sudarymas su `Path`

Vienas didžiausių `pathlib` privalumų – kelius galime patogiai konstruoti naudodami `/` operatorių:

```python
from pathlib import Path

directory = Path("data")
file_path = directory / "animals.txt"

print(file_path)
```

Rezultatas:

```text
data/animals.txt
```

Galime sudaryti ir ilgesnius kelius:

```python
path = Path("data") / "animals" / "cats.txt"
```

Tai yra patogiau ir universaliau nei rankiniu būdu jungti tekstą:

```python
"data/" + "animals/" + "cats.txt"
```

---

# 16. Failo egzistavimo tikrinimas

Su `Path` galime patikrinti, ar failas arba katalogas egzistuoja:

```python
from pathlib import Path

path = Path("animals.txt")

if path.exists():
    print("Egzistuoja!")
else:
    print("Nėra.")
```

Galime atskirai patikrinti, ar tai failas:

```python
path.is_file()
```

ar katalogas:

```python
path.is_dir()
```

Pavyzdžiui:

```python
if path.is_file():
    print("Tai failas.")

if path.is_dir():
    print("Tai katalogas.")
```

# 18. Katalogų kūrimas

Katalogą galima sukurti su `mkdir()`:

```python
from pathlib import Path

directory = Path("data")
directory.mkdir()
```

Jeigu katalogas jau egzistuoja, gausime klaidą.

Dažnai naudojama:

```python
directory.mkdir(exist_ok=True)
```

Tada klaidos nebus, jei katalogas jau yra.

Jeigu norime sukurti kelis katalogų lygius:

```python
directory = Path("data/animals/cats")
directory.mkdir(parents=True, exist_ok=True)
```

Python prireikus sukurs visą struktūrą:

```text
data/
└── animals/
    └── cats/
```

---

# 19. Katalogo turinio peržiūra

Su `iterdir()` galime peržiūrėti katalogo turinį:

```python
from pathlib import Path

directory = Path("data")

for path in directory.iterdir():
    print(path)
```

Pavyzdžiui:

```text
data/animals.txt
data/users.txt
data/photos
```

Galime atskirti failus nuo katalogų:

```python
for path in directory.iterdir():
    if path.is_file():
        print("Failas:", path)
    elif path.is_dir():
        print("Katalogas:", path)
```

# 20. Failų paieška su `glob()`

Jeigu norime rasti tik tam tikrus failus, galime naudoti `glob()`.

Pavyzdžiui, visus `.txt` failus:

```python
from pathlib import Path

directory = Path("data")

for path in directory.glob("*.txt"):
    print(path)
```

Jeigu kataloge yra:

```text
animals.txt
users.txt
photo.jpg
notes.txt
```

bus rasti:

```text
animals.txt
users.txt
notes.txt
```

`*` reiškia „bet kokie simboliai“.

Todėl:

```text
*.txt
```

reiškia „bet koks failo pavadinimas, kuris baigiasi `.txt`“.

---

# 21. Failų skaitymas su `Path`

`Path` objektą galima naudoti kartu su `open()`:

```python
from pathlib import Path

path = Path("data") / "animals.txt"

with open(path, encoding="utf-8") as file:
    print(file.read())
```

Tačiau pats `Path` turi ir patogų metodą tekstui perskaityti:

```python
content = path.read_text(encoding="utf-8")

print(content)
```

Taip pat galima įrašyti tekstą:

```python
path.write_text("Katė\nŠuo\n", encoding="utf-8")
```

Svarbu: `write_text()` pakeičia visą egzistuojantį failo turinį, panašiai kaip `"w"` režimas.

---

# 22. Klaida, jei failo nėra

Jeigu bandysime skaityti neegzistuojantį failą:

```python
with open("unknown.txt", encoding="utf-8") as file:
    print(file.read())
```

Python pateiks:

```text
FileNotFoundError
```

Galime prieš skaitydami patikrinti:

```python
from pathlib import Path

path = Path("unknown.txt")

if path.exists():
    print(path.read_text(encoding="utf-8"))
else:
    print("Failas neegzistuoja.")
```

Arba galime apdoroti klaidą:

```python
try:
    with open("unknown.txt", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("Failas neegzistuoja.")
```

# 24. Praktinis pavyzdys – failo eilučių skaičiavimas

```python
from pathlib import Path

path = Path("notes.txt")

if path.exists():
    with open(path, encoding="utf-8") as file:
        count = 0

        for line in file:
            count += 1

    print("Eilučių:", count)
else:
    print("Failas neegzistuoja.")
```

path.is_dir()

path.mkdir(parents=True, exist_ok=True)
